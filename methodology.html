PROJECT DEVELOPMENT

Methodology and System Implementation

An overview of the development approach, technologies, system architecture and risk assessment techniques used in this project.

DEVELOPMENT APPROACH

Development Methodology

The system was developed using an iterative development approach. This involved identifying system requirements, designing the system, implementing individual modules and testing their functionality. The development process allowed individual components to be implemented and evaluated progressively to ensure that the system met its intended objectives.

SYSTEM STRUCTURE

System Architecture

Presentation Layer

Provides the user interface through HTML templates and CSS styling. Users interact with the system through its web pages and forms.

Application Layer

Uses Python and Flask to process requests, validate information, perform risk calculations and coordinate system operations.

Database Layer

Uses SQLite to store assets, threats, vulnerabilities and risk assessment records in a structured database.

CORE COMPONENTS

System Modules

1. Asset Management

Allows users to register, view, update and delete organisational information assets.

2. Threat Identification

Records potential cybersecurity threats associated with registered assets.

3. Vulnerability Assessment

Identifies and records weaknesses that could be exploited by threats.

4. Risk Assessment

Evaluates identified risks using likelihood and impact ratings.

5. Risk Register

Maintains a centralised record of assessed risks and their ratings.

6. Risk Dashboard

Presents summary statistics, risk distribution and recent assessment records.

RISK EVALUATION

Risk Assessment Technique

The system uses a numerical risk assessment approach based on the likelihood of a threat occurring and its potential impact on an asset. Both factors are rated on a scale of 1 to 5.

Risk Score Formula

Risk Score = Likelihood × Impact

The resulting score is used to classify each assessed risk into one of four levels.

Risk Score Risk Level
1–4 Low
5–9 Medium
10–16 High
17–25 Critical
